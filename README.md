Perancangan Aplikasi Pengelolaan Stok Mobil pada Sistem Rental Berbasis Web merupakan sebuah aplikasi berbasis web yang dirancang untuk membantu pengelolaan data dan stok mobil pada usaha rental kendaraan.
Aplikasi ini dibuat untuk mempermudah proses pengelolaan informasi mobil, seperti menambahkan data mobil, mengubah data mobil, menghapus data mobil, serta memantau ketersediaan mobil yang dapat disewakan.
Dengan adanya sistem berbasis web ini, proses pengelolaan stok mobil diharapkan menjadi lebih terstruktur, cepat, dan mudah diakses dibandingkan dengan pencatatan secara manual.
